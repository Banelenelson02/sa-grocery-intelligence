# Grocery image assets

Place the downloaded images in this directory using these exact filenames:

- `grocery-hero.jpg`: wide grocery basket or supermarket produce image used in the catalogue hero.
- `produce.jpg`: fresh fruit and vegetables.
- `dairy.jpg`: milk, cheese and other dairy products.
- `meat.jpg`: packaged meat or poultry display.
- `staples.jpg`: bread, rice, pasta and pantry staples.

The product catalogue references these local files from `/public/images`. Keep the original photographer and source details when downloading and retain any applicable licence terms. The photos are illustrative category imagery, not verified photographs of the exact products or retailer listings in the database.
